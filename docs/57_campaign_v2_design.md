## 1 为什么另起一个模拟核心

M2 的战役跑在旧引擎上：4 个部门的投入产出表、6 类买方的逐一撮合、五分量定价、六条互相咬合的企业现金规则。M2-8 标定一整轮只做到「不崩盘」，两条路线与无操作局 50 年后失业率都在 46%—62%，玩家的选择几乎不改变结果。docs/54 的减法清单要动的正是这些核心，而它们与公共服务、住房、教育、研究、GDP 口径在 8 个步骤里互相缠绕，逐条外科手术只会得到一个更难维护的拼接物。

所以 v2 **为四百年战役另写一个模拟核心**，按本文件的设计从头组织，以商品和配方为骨架。原则沿用旧工程：整数定点、确定性、命令流与重放、金额两两对平、每季自检。旧引擎保留给「澄湾共和国」教学剧本与旧战役剧本，现有测试全部保持不变。

## 3 地区、人口与阶层

**4 个地区**，各有土地与资源禀赋（决定能建什么、建多少）：

| 地区 | 特点 | 土地 | 矿藏与其他 |
|---|---|---|---|
| 北原 | 北方平原，人口最多 | 旱地多、草场 | 煤（浅层）、石料 |
| 中州 | 大河中游，首府所在，商贸中心 | 水田多、少量坡地 | 瓷土、河运 |
| 海岬 | 东南沿海 | 水田、少量旱地 | 盐、渔场、良港 |
| 西岭 | 西部山地，人少 | 坡地、林地 | 铁、铜、硫磺，水力 |

**4 个阶层**（每个地区各一组，共 16 组）：

| 阶层 | 做什么 | 收入来源 |
|---|---|---|
| 农户 | 种地、放牧、打鱼、伐木 | 工钱 + 自耕收益 |
| 工匠 | 作坊、矿场、营造、运输 | 工钱 |
| 商贾 | 买卖、钱庄、经营作坊 | 工钱 + 作坊与商铺利润 |
| 士绅 | 读书做官、收租、教书、研究 | 地租 + 俸禄 + 工钱 |

阶层之间会流动：有作坊招工、村里又有闲人时，农户进城成为工匠；读书的人多了，士绅变多；商业兴旺，工匠转为商贾。流动慢而可见。

## 4 商品与产业链

### 4.1 规则

1. **商品是一等公民**。每种商品有层级（原料、半成品、成品、资本品）、所属部门（农、工、能、服，用于统计）、基准价、单位、时代区间、每季损耗。
2. **全国一个市场**。地区之间靠物流系数区分：卖出时生产者拿到「市价 ×（1 − 物流成本）」，修路、开运河、建港口降低物流成本。
3. **价格 = 基准价 ×（1 + 稀缺溢价）**。溢价随供求差平滑变化，有上下限；有进口时不高于进口价，有出口时不低于出口价。价格涨跌的原因一句话说得清。
4. **同季按层级生产**：原料先产，半成品用本季原料，成品用本季半成品。耐用投入（农具、役畜）用季初库存，打破循环。
5. **缺料只降那座作坊的开工率**，不在全国连锁放大；缺口可进口（受港口与商路能力约束）。
6. **软约束**：任何建筑都能在任何地区建。本地缺原料、缺人手、缺土地时，建造卡上用黄色提醒写明预计开工率与原因。土地是物理上限：一个地区的农田不能超过它的耕地。

### 4.2 四个时代的主要产业链（活跃商品随时代更替，见 content_v2）

**第一时代 · 农商（1600—）**

| 链 | 原料 → 半成品 → 成品 |
|---|---|
| 口粮 | 稻米（水田）、麦粟（旱地）、豆类 |
| 棉布 | 棉花 → 纱线（纺纱坊）→ 布匹（织布坊） |
| 丝绸 | 桑园 → 蚕茧 → 生丝（缫丝坊）→ 绸缎（织绸坊） |
| 麻与船具 | 麻 → 绳索、帆布（绳帆坊）→ 船运能力 |
| 铁 | 铁矿石 + 木炭 → 生铁（冶铁作坊）→ 铁器（铁匠铺）→ 农具增产 |
| 铜 | 铜矿石 + 木炭 → 铜材 → 器物、铸钱 |
| 瓷 | 瓷土 + 木炭 → 瓷器（瓷窑） |
| 木 | 原木 → 木炭（炭窑）、板材（锯木坊）→ 家具、营造 |
| 油与皂 | 油籽 → 食用油（榨油坊）→ 蜡烛（皂烛坊） |
| 酒 | 麦粟 → 酒（酿坊） |
| 纸与书 | 原木 / 麻 → 纸张 → 书籍（印坊）→ 识字、研究 |
| 牧 | 草场 → 役畜、肉、生皮、羊毛；生皮 → 皮革 |
| 其他 | 盐（盐场）、鱼（渔场）、茶叶（茶园）、蔬菜、石料、砖瓦（砖瓦窑）、粗陶 |

**第二时代 · 工场与商路**：甘蔗 → 蔗糖；水力纺纱与织布；煤取代部分木炭；玻璃；磨坊（麦粟 → 面粉）；远洋贸易带来香料、咖啡、可可；钱庄与商业信贷；运河。**木材枯竭**是这一时代的主要压力。

**第三时代 · 蒸汽与铁路**：煤 → 焦炭；生铁 + 焦炭 → 钢材 → 机械、钢轨、铸件、锅炉；石灰岩 + 煤 → 水泥；硫磺、盐 → 化学品 → 化肥；罐藏食品、面包、啤酒、成衣；煤气；动力由蒸汽机提供（耗煤）；铁路大幅降低物流成本。

**第四时代 · 电气与现代国家**：电力（电网跨区输送）；原油 → 燃料油、塑料；铝土矿 → 铝材；铜 → 电缆 → 电动机、变压器；电子元件 → 收音机、电视机、计算机；家用电器、机动车；药品；太阳能电池（末期）。

### 4.3 需求

每个阶层有一份**需要清单**，按优先级排列：口粮、盐、衣、燃料、副食、器用、文教、享乐。每项可以由几种商品满足（如口粮：北原偏麦粟，中州、海岬偏稻米，豆类可替代）。居民按上季收入与储蓄决定预算，先满足前面的项目。**满足程度**就是民生的直接量度，界面上逐项显示「口粮 96%、盐 100%、衣 78%……」。时代越往后，清单越长、期望越高（第三时代要成衣与糖，第四时代要电器与汽车）。

## 5 生产、就业与企业

每座建筑（同地区、同类型、同所有者、同生产方式合并为一「堆」，有「规模」若干级）按配方运作：

- **配方** = 每级每季的产出、投入、各阶层用工、土地、动力需求、维护费。
- **开工率** = min（人手到位率、各项投入到位率、动力到位率、土地、销路），每一项都有一句话原因。
- **用工**：各地区各阶层按比例分配；缺人时按比例开工不足，闲人多时工钱缓慢下降。
- **工钱**：按阶层基准，随用工紧张程度在 0.6—2 倍之间缓慢调整。
- **核算**：收入 − 工钱 − 投入 − 维护 − 税 = 利润。利润当季分给所有者：农业的地租份额归士绅、其余归农户；作坊与商铺归商贾；官营归国库。**企业不留现金**，所以不存在旧引擎那种「缺现金 → 少招工 → 更缺现金」的暗棘轮。亏损由所有者的储蓄承担，承担不起时欠薪，并在界面上写明。连续亏损的民间作坊会自行缩小。
- **民间投资**：商贾与士绅的闲钱按「营商环境」的比例投入新建与改造，挑预期回报最高的建筑与地区，每季至多几项，写进纪事。玩家通过修路、开港、水利、政令、税率、研究来引导它，也可以官办。

## 6 财政

**第一时代的收入**：田赋（在册田亩的农产值 × 科则）、盐课（每担盐征）、商税（非农产品销售额的小比例）、关税（进出口额）、官营收益。**隐田**每年侵蚀在册田亩，清丈能追回，但得罪士绅。征收要靠吏员：官俸拨款不足时征收率下降。

**支出**：官俸、军饷、教育、赈济、工程维护、利息，外加官办建设与项目。每项拨款可在 0—150% 之间调整，各有看得见的效果（征收率、边患风险、识字率、灾年死亡）。

**后续时代**：第二时代钱庄出现、可以借商债；第三时代所得税、关税则例、铁路收入；第四时代中央银行、社会保险。

现金不足时依次欠俸、欠饷，民心与合法性下降，财政危机推进。

## 7 贸易

伙伴各有「想买」与「能卖」的商品清单、价格系数、每季上限，各有自己的发展进程与知识。海路伙伴受港口能力约束，陆路伙伴（内陆汗国）受商路能力约束。出口换回白银，进口补国内缺口。玩家的杠杆：开海或海禁、关税、签商约（花钱与关系，改善价格与上限）、遣使译书（加速研究）。

---

## 8 研究

约 40 项科技，分属四个时代。研究点来自读书人、学舍与书院、后期的研究机构。**只加速、不硬锁**：国内相关产业越发达、与已掌握该技术的伙伴贸易越多，研究越快；科技卡上写明加速来源。

## 9 时代、世界与地标

- **本国时代**按门槛前进：本时代关键科技若干项 + 标志设施若干类 + 一项社会条件（识字率或城镇化）。门槛与进度一直显示在时代面板上。
- **世界**：每个伙伴各有发展度，随机但有惯性，互相扩散；最先进伙伴决定「世界前沿」。本国先于前沿进入某时代即为**引领**：先发红利（新商品出口价加成，随世界追赶衰减）、人才流入、国望、地标、编年史称号。
- **落后**时出口竞争力下降、民众期望上升、伙伴态度变差。不作为的国家越落越远，最终经危机倾覆。
- **地标**：第二至第四时代各有三座候选；引领时选一座建完整版，其余只能建降级版（效果减半、无国望）。第一时代有成就地标（贡院、古天象台、公共义仓总库）。

## 10 改造：时代更替后旧产业的去留（用户意见 3）

一个「改造」面板，把所有能改造的建筑列在一起，按「回本年数」排序：

| 操作 | 做什么 |
|---|---|
| **升级** | 换成新生产方式。花新建价的一部分，改造期间开工减半 |
| **一键升级** | 同一类或同一地区的全部过时建筑一起升级 |
| **合并** | 同地区几堆过时建筑合并成一堆新式的，比分别升级便宜；多出来的工人进入闲置 |
| **封存** | 停产、只付一成维护，以后可以重开 |
| **拆除** | 回收一点残值，腾出土地 |

民间所有的建筑由所有者自己按回本年数改造；玩家主要管官办的，或用补贴引导。公共设施（学舍、藏书院、医馆、粮仓、水利）不会过时，但可以原地**换代**，不换代则效果停在旧时代的水平。带时代标签的加成（如贡院的科举选才）在本国进入后两个时代后逐步失效，可转为新式学堂或列为古迹。

## 11 轻托管（用户意见 4）

每个领域可选**亲自处理**、**托管**或**托管但需我批准**，并给一个**方针**：

| 领域 | 负责 | 方针选项 | 托管做什么 |
|---|---|---|---|
| 研究 | 学政 | 均衡 / 重农 / 兴工 / 通商 / 文教 | 挑下一个研究方向（看缺什么、哪项有加速、离下一时代还差什么） |
| 营造 | 工部 | 补短板 / 保民生 / 兴产业 / 均衡 | 在预算内建最值得建的：缺口最大、进口最贵、闲人最多的地方 |
| 改造 | 工部 | 回本 N 年以内才改 | 升级、合并、封存官办的过时建筑 |
| 贸易 | 市舶司 | 保供 / 创汇 | 调整商约与关税，处理缺口与积压 |
| 财政 | 户部 | 稳健 / 宽松 | 在上下限内调税率与拨款，保持国库不低于警戒线，必要时借债 |
| 事件 | 通政司 | 保民生 / 保财政 / 保稳定 | 按方针回应事件 |

**不笨的关键**：托管读的是与顾问同一份分析（缺口、回本、民生、财政跑道），带预算上限、冷却期与滞后，不会反复横跳；每个动作都写一句理由，进本季纪事；「需我批准」模式下动作先进草案篮，玩家可逐条删掉。

## 12 顾问（用户意见 5）

五位顾问：户部（财政）、工部（营造与产业）、学政（研究与教育）、民政（民生与人口）、市舶（贸易与外事）。每季由分析模块给出候选建议并排序，**最多显示三条**，每条包括：一句话结论、一两句带数字的理由、一个「照此办理」按钮（直接放进草案篮）或「去看看」链接。

**适时**：只在条件触发时开口（趋势连续恶化、跑道短于一年、新技术带来高回报改造、伙伴开出好条件、时代门槛只差一步……）；同一件事被忽略后要冷却一段时间才会再提；顾问之间可以意见不同，并排给出。

## 13 地图（用户意见 1）

新地图用程序绘制，风格为深色底上的「舆图」：海面有细波纹，海岸线双线描边，山地用成组的山形笔触，林地用点簇，大河从西岭经中州入海，地区边界为虚线，首府与城镇为方形印记。

- **图层**：民生、繁荣、缺口、失业、识字、在建。按地区着色，图例写成普通话。
- **地区上的标记**：主要产业的小图标（用 Codex 的建筑图缩略）、缺口警示。
- **外贸航线**：海路伙伴在东、南海面，陆路伙伴在西；线宽表示贸易量，端点是伙伴徽记。
- **悬停**：显示地区卡片，卡片上有该地区当前时代与状态的场景画（Codex 地区场景图）与三五个关键数字；点击进入地区页。

若 Codex 另绘一张底图，渲染器会优先使用底图、只叠加交互层（见 §16）。

## 14 用语规范（用户意见 2）

1. 句子要像对人说话：「北原粮食不够吃」，不写「北原·农业·口粮缺口」。
2. 不出现规则编号、账目编号、变量名、ppm、μU、Q_ 之类；需要追溯时，放在「查看明细」里，默认收起。
3. 不用自造缩写。「实·算·预」改为「已发生 / 按规则算 / 预计」，并用颜色与图标区分，不在每句话前加前缀。
4. 数字少而准：金额到万两，比例到整数百分点，趋势用「比上季多 3%」。
5. 每个术语第一次出现时可以悬停看解释，解释用一句大白话。
6. 按钮写动作：「建一座」「升级全部」「照此办理」。

## 15 界面

**主界面**：顶栏（年份季节、时代、国库、民心、警示数，按钮：顾问、托管、帮助、存档）；页签「国情 · 地区 · 产业 · 科技 · 政令与财政 · 民生 · 外贸 · 纪事」；底栏（本季草案、国库预计，推进一季 / 一年 / 五年）。

| 页 | 内容 |
|---|---|
| 国情 | 地图（主角）、四个大数（国库、民生、产值、民心）、本季要务、顾问进言、时代进度 |
| 地区 | 场景画头图、土地与资源、建筑列表、各阶层生活、民心 |
| 产业 | 商品链图（点开一种商品看上下游与供需）、建设（带软约束提醒的建造卡）、改造中心 |
| 科技 | 分时代的科技树，写明加速来源与解锁内容 |
| 政令与财政 | 政令（开关与级别）、税率、拨款、收支、债务 |

| 外贸 | 伙伴卡（徽记、想买能卖、关系、商约）、进出口 |
| 纪事 | 季度纪事（发生了什么、托管做了什么、顾问说过什么）、历年曲线 |

**覆盖层**：确认推进（简化）、事件（配事件画）、时代更替（章节画）、托管设置、顾问全文、帮助与术语。

## 17 不操作必须亡国（验收口径）

无操作局的压力来源都是公开的：隐田侵蚀田赋、吏治松弛、人口增长压过粮食、灾年、世界进入新时代后的差距。目标：多数种子在 1650—1730 年间经危机倾覆，且倾覆前至少两年有顾问警示与危机进度。托管局（均衡方针）应能稳住并在 1680—1740 年前后进入第二时代；不同方针的结果要有明显差别。
