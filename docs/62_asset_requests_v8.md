## 0 通用要求

沿用第七批（[docs/60](60_asset_requests_v7.md) §0）的全部要求：画风与现有资源一致，时代感要对，**不出现文字**，透明图四周留约 8% 的边，文件名小写英文加下划线，交付时附审核页、清单与提示词，待用户初审。

另外，这一批题材敏感，特别注意：

- **不用真实国旗、真实政党标志、真实领袖肖像、宗教符号**；军装、旗帜、徽章都用虚构的样式（色块、几何纹、星、麦穗、齿轮、锚这类通用元素可以用）。
- 战争、革命、镇压**克制表现**：不画流血、尸体、处决；用人群、旗帜、硝烟、紧闭的城门、空荡的街道这类意象。
- 人物沿用第七批的几何主义画法（简化块面、少量身份道具）。
- 「列强」是虚构的外国：海军、洋装、蒸汽兵舰都可以画，但不要指向某个真实国家。
