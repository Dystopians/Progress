# 经纬：400 年国家发展改造规划 v0.2

更新：2026-09-22 · 编写：Codex · 状态：用户主要方向已确认；机制细节仍是提案，尚未实施，待 Claude 技术评审。

## 0. 决策状态与适用边界

**用户已明确的方向**：1600—2000 年，时间跨度跨越 400 年，从农业商贸走向信息时代；有科技树；有不同时代的建筑选择与升级；尽可能复用当前工程；正常施政持续控制，严重施政失败、极端失误或可避免的重大军事失败才可能结束；发展为主，外交贸易与抽象战争；建筑采用卡片和列表，玩法参考《维多利亚3》这类方向。Codex负责图片资源、审视文本与玩法、提供可玩性设计指导，并持续维护给Claude的协作信息。用户要求设计问题直接询问。

**本稿提出而未获用户确认的默认值**：架空国家、六阶段、4地区、36群组、季度内核、按年/多年推进、48个科技节点、12类经济/公共建筑家族与36个变体。数量是内容预算，不是已经存在的功能或承诺的工期。具体失败阈值、外部伙伴数量与军事支持设施预算仍待设计；政府更替自动形成篇章是对持续控制目标的实现建议。

本稿改变产品目标的建议，不自动覆盖 `docs/18` 或 `docs/10—17` 的执行契约。旧版仍按原规则运行。确定新规则后，先追加裁定，再更新契约、代码与验收。最新用户方向优先于旧计划的产品范围；详细机制仍需明确落档，不能把本文的例子当成已实现规则。

## 1. 新的游戏承诺

一句话：**带领一个架空国家走过四百年，在技术、建设与制度的相互推动中塑造发展道路，并处理旧选择留下的长期后果。**

玩家长期扮演国家发展方向的决策者，不是生存四百年的同一位总统。执政团队、制度、社会集团与经济基础会变化；地区、设施、债务、知识和历史记录构成跨代继承。

采用“产业与社会发展”的操作重心：玩家主要从建筑卡片、生产方式、贸易选择和政策方案介入，地图作为地区差异与结果展示，不做自由摆放或道路拼接。

核心体验是“看见一个问题 → 选择解决路径 → 获得知识与配套 → 建设或改造 → 看见地区变化 → 应对新的社会需求”。账本与因果追溯保留为可信底座，主界面优先展示可行动的问题和发展成果。

一局应留下能复述的故事，例如：北原先办学校与水利、海岬先靠贸易引入设备；工业化后城市住房与劳动关系成为新难题；旧燃煤设施保住了就业，也使后期清洁改造更昂贵。故事必须由状态和命令产生，不能靠随机文案假装发生。

## 2. 时间与玩家注意力

### 2.1 推荐固定季度内核，改变操作节奏

- 400 年 = 1,600 个季度。日历保存起始年和绝对季，显示真实年份；所有工期、票息、人口变化和季节性仍使用季度。
- 默认每年规划一次，提供“推进一季”“推进一年”“按现有安排推进至多五年”。推进一年依次执行四个季度，绝不把一次季度计算乘以四。
- 多年推进只执行已经批准的安排；不自动购买科技、选择事件答案、发起新建筑或切换制度。自动维护、现有合同、规则融资必须在设置中公开其边界。
- 技术完成、需选择的事件、重大建设完成、首次出现的资金缺口、制度转换、阶段里程碑触发暂停；同季同类消息合并成一份摘要，避免弹窗轰炸。
- 命令前置条件按每一季重新校验。若暂停发生在季末，本季先完整结算并保存，下季新命令尚未执行；若本季开始前已发现待选择事项，则留在 IDLE，不能停在半个结算步骤。
- 用户可随时在季度边界停止自动推进。交互调度每完成一季让出界面线程；先测一年的响应时间，不承诺未经测量的五年瞬时运行。

### 2.2 操作密度目标（需试玩验证）

完整战役建议作为可分多次完成的 6—10 小时体验，目标约 80—150 个值得停下来思考的规划节点；这不是硬性每若干年触发的任务表。平稳年份可以快速经过，危机与转型阶段需要细看。用 50 年切片的实测节奏外推后再修订目标。

首版不做随时代改变“一回合代表几年”的变步长模拟：那会同时破坏复利、工期、老龄化、事件概率、债券与回放。若固定季度性能仍不可接受，另立裁定，不用跳过结算掩盖问题。

## 3. 六个发展阶段：时代提供主题，条件决定转型

以下日期只是架空剧本的章节窗口，不声称是现实发明史，也不强制到点解锁。不同技术线、不同地区可以同时处在不同水平。

| 章节窗口（默认提案） | 阶段主题 | 玩家主要选择 | 可见变化 |
|---|---|---|---|
| 1600—1660 | 农业与地方治理 | 粮食余量、水利、地方征收、识字投入 | 农庄、水利、集市、地方学舍 |
| 1660—1730 | 商贸与工场 | 水运/道路、商贸专门化、工场与技能培养 | 码头、仓储、工场、印刷与书院 |
| 1730—1800 | 机械化起步 | 动力替代、矿业配套、技术引入或自主研究 | 动力工场、矿井、工程学校 |
| 1800—1880 | 工业与城市 | 重工业/轻工业路径、铁路、城市公共卫生 | 工厂、铁路枢纽、工人住宅、供水 |
| 1880—1950 | 电气化与公共服务 | 电网覆盖、生产组织、医疗教育普及 | 发电与变电设施、医院、现代学校 |
| 1950—2000 | 自动化与信息 | 节能改造、科研、自动化与就业调整 | 自动化工厂、研究设施、通信节点 |

时代不是统一加成按钮。满足关键知识、试点投运和配套条件后，相关体系可以转型。国家的时代标题是叙事摘要，不替代地区与行业的真实状态。不能要求全树点满才能进入下一章，也不能让升级一栋房子自动改变全国制度。

开始时使用“澄湾”作为国家通称；“共和国”等政体称谓根据制度决定。现代税制、国债市场、电网和失业保险不能原样出现在前工业时期。

## 4. 科技：发现、试点、推广三件事

### 4.1 内容结构

完整目标为六条方向、每条约八个节点，共 48 个；节点跨方向设少量必要依赖，不做六根互不相干的直线。

| 方向 | 示例节点（架空技术谱系，非历史时间断言） | 主要解锁 |
|---|---|---|
| 农业与资源 | 测绘水利、轮作组织、农业机械、资源勘测 | 农业生产方式、设施与资源开发 |
| 动力与工业 | 水力机械、蒸汽动力、精密加工、电动机、自动控制 | 工场/工厂配方与改造 |
| 交通与贸易 | 道路工程、仓储标准、铁路运输、港口机械化 | 网络容量、物流设施与贸易工具 |
| 教育与科研 | 基础识字、印刷传播、工程教育、研究机构 | 技能培养、研究产出与知识吸收 |
| 健康与城市 | 公共供水、卫生管理、基础医疗、现代医疗 | 城市承载、服务配方与卫生能力 |
| 财政与行政 | 地籍登记、统一核算、公共信用、专业征管、信息管理 | 征收方式、融资制度与行政工具 |

每节点至少包含：前置知识、研发成本、需要的设施/人才、完成效果、可落地行动、受益/受损方向、配套缺口提示。纯“全部产量 +5%”节点不能充当主干节点；效率提升必须有明确作用对象与机制。

### 4.2 研究资源与选择

- 首个切片只开放一个主动研究课题，另一个槽位是否加入由玩法测试决定。避免开局同时推进所有方向。
- 研究来自学校/研究设施的人员、经费与服务交付：钱进入既有工资/采购账，研究进度作为独立非货币产出登记；不是凭空把 GDP 换成科技点。
- 自主研究与知识引入提供不同取舍：自主更慢但可按本国条件发展；引入需要贸易关系、支付和吸收能力。最小切片先实现自主研究，引入路线在后续阶段加入。
- 暂停课题保留已经获得的知识；切换产生明确的时间/组织成本，不能靠反复切换复制进度。投入不足只减慢进度，不偷偷扣除已完成科技。
- 科技完成只解锁资格。建试点、培养工人、采购设备、提供动力之后才有经济效果。先进技术可因缺乏配套而暂不适用。
- 大部分路径可并行学习，但早期投资形成沉没成本；互斥只用于明确的生产方式或制度选择，转换必须可说明代价，避免不可逆误点毁掉百年存档。

示例链：工程教育 + 动力知识 → 解锁动力工场改造 → 支付设备与停工成本 → 配套燃料与技术工人 → 提高实际产能 → 城市迁入与住房需求上升。若燃料不足，科技图显示“已掌握、尚未部署”，而不是宣称全国增产。

## 5. 建筑：可见的设施、分支和改造，不做换皮等级

### 5.1 内容预算与家族

完整版本先控制在 12 个建筑家族、每类约 3 个关键变体，共 36 个可建/可改造定义。六个时代不要求每类都有六级。生产方式、规模和建筑外观分开定义，减少重复内容。

| 家族 | 三个候选形态 | 主要取舍 |
|---|---|---|
| 农业水利 | 地方渠系 → 区域灌溉 → 机械排灌 | 粮食与土地/水资源/动力需求 |
| 农业生产 | 综合农庄 → 商品化农场 → 机械化农场 | 劳动密集/设备密集、产出与就业 |
| 工场工业 | 手工工场 → 动力工场 → 电动工厂 | 就业、能源、技能与生产率 |
| 矿业资源 | 地表采掘 → 深井矿场 → 机械采掘 | 资源供给、事故与环境成本 |
| 动力设施 | 水力动力站 → 热力动力站 → 电力设施 | 地点条件、燃料依赖与污染 |
| 交通枢纽 | 驿路节点 → 铁路枢纽 → 综合物流站 | 初始成本、容量与长期维护 |
| 港口仓储 | 河港仓栈 → 商贸港区 → 机械化港区 | 对外依赖、设备交付与出口能力 |
| 居住设施 | 集镇住宅 → 工人住宅 → 配套社区 | 密度、住房承载与服务配套 |
| 教育科研 | 学舍 → 工程学校 → 研究机构 | 识字、技能、研究的资源分配 |
| 医疗设施 | 地方诊所 → 公共医院 → 区域医疗中心 | 覆盖面、专业人员与持续开支 |
| 城市公用 | 水井与排水 → 供水卫生设施 → 综合公用设施 | 城市承载、健康和运行维护 |
| 财政行政 | 地方登记所 → 税关与核算机构 → 现代行政中心 | 征收、贸易与行政流程负担 |

以上是候选定义，不把“水力站必然升级为燃煤站”等不符合地点条件的线性关系写成强制路线。可以旁建、保留、改作他用或退役；高一级不意味着在所有地区都更划算。

### 5.2 每个设施的操作

设施展示：地区、所有者、用途、规模、生产方式、状态、员工需求、输入/输出、维护、升级条件。玩家能比较五种行动：新建、扩建、改造、停用封存、退役。切片先实现新建与改造，其余按阶段加入。

- 扩建增加数量，仍使用原生产方式；受土地/承载、人员和资源约束。
- 改造改变生产方式，可短期停产，必要时分期施工；费用与损失必须事先列出。不能同时享用旧设施完整产出与新设施完整产出。
- 先进建筑仍会遇到缺人、缺料、缺动力、缺市场的问题。
- 旧设施保留可能便宜、就业多、维护简单；新设施可能节约劳动但提高设备和能源依赖。替代关系应能产生至少两条合理路线。
- 退役处理雇员、残值、维修欠账与环境责任；不把“拆除”当作免费退款。
- 建成日期、重大改造与所在地区进入历史档案，支持跨时代前后对照。历史价值首先是可见记录，不凭空附加永久数值收益。

### 5.3 所有权与现有经济的连接

四个市场部门目前按地区聚合为 16 个生产单元，不宜立刻改成每栋楼一个完整企业账户。

建议首阶段设施拥有稳定实例 ID，现金仍结算到已有政府或地区部门账户；公共设施走政府项目，产业设施走所属部门投资与政府支持规则。**产业建筑的详细所有权/投资命令接口必须由 Claude 先裁定**：政府发起建设计划不等于可以免费支配企业现金。

最低可接受合同是“明确出资主体 → 明确设备/施工收款方 → 明确资产归属 → 明确分红/税收口径”。若切片没有完成这一合同，先只开放公共设施和现有企业自主投资的可视化，不伪装成玩家已能任意建工厂。

这只能作为M1技术演示的暂态；**M2玩法切片必须至少有一种玩家可主动投资/支持并改造的产业设施**，否则不能以三个公共服务按钮代替用户要求的产业建设体验。可用“国有试点工场”或有明确共同出资合同的产业项目完成，选择由T-002评审落定。

楼的能力与旧资本数组只能有一份权威来源：设施表生成地区部门汇总，旧资本数据先映射为存量设施；不能旧资本产能照算，再把新设施产能重复叠上去。施工槽位只约束同时施工，不能兼作永久建筑占地上限。

### 5.4 建筑列表与生产方式（按用户反馈新增）

- 默认按“地区 × 建筑类型 × 所有者/生产方式”合并显示等级，不让玩家管理数千个重复实例。实例批次仍用于后台记录建造、改造和旧设施差异。
- 建筑卡主列：等级、当前生产方式、就业/空缺、投入短缺、产出、收支/盈利口径、补助、施工状态。点击展开工资、税负、所有权、环境与供应链。
- 生产方式分组建议从“核心工艺”和“动力/节省劳动方式”两组起步，不一次铺五六个下拉框。相互不兼容的组合由数据约束，UI解释原因。
- 改造预览并列旧/新方案：一次性开支、停产期、每季投入、各技能岗位、产出上限和配套。先改造一批验证，再允许选定地区/行业分批推广；批量命令逐项校验，失败项保留清楚回执。
- 不能默认“切到最新方法”总是最优。廉价劳动力、能源进口依赖、技术工人不足、就业冲击都可能支持保留旧方法。
- 市场观察需能从“某产品短缺”跳到供应建筑、贸易来源和替代方案；只给GDP图不足以支撑这种玩法。M2至少让玩家看到一次投入短缺→扩供应/进口/改工艺的选择。

## 6. 经济、资源与人口的时代适配

### 6.1 先保留可维护的规模

切片保留 4 地区、4 个顶层部门、36 群组、3 个集团槽位。先证明科技与建筑改变玩法，再扩大地图和人口粒度。早期三集团可映射为土地/商贸/劳动公共事务三类组织，但成员、组织力、名称与否决范围需要随制度和生产结构变化；这属于机制改造，不只是改显示名。

### 6.2 资源深度分两步

早期用可追溯的技术配方改变四部门的劳动、材料、动力和运输需求，减少立刻扩充全部投入产出维度的风险。前工业动力包含人力/水力/燃料条件；“电力约束”必须由技术条件启用，不得让未通电农庄因没有电网停产。

若原四类产品无法形成有趣的生产链，第二阶段增加独立实物品类（候选：粮食、木材、煤、金属、机械、电力等），与四个会计部门分开映射。任何对外宣称“消耗煤”的设施都必须真的有煤库存、购买、运输和消耗约束；不能只画一个煤图标却仍无条件增产。该扩展须另列工程预算，不能算作零成本复用。

### 6.3 四百年标定不可沿用十年参数

重新标定人口出生死亡与迁移、技能培养、土地住房容量、资本寿命、价格工资边界、资源可得性、征税制度和冲击强度。要避免人口/名义价格指数增长溢出、社会需求过早饱和、自动折旧使世界必然崩塌。

“生活改善 → 新需求”是主循环：生存保障之后出现教育、卫生、住房质量与技能需求，旧设施继续有用但需要调整。以显式需求和服务配方表达，不用时代全局倍率修改所有人的满意度。

维护作为可配置、可停止的既定安排进入预算，允许运行良好的国家在稳定时期自动维持；不能要求玩家四百年反复点击同一个维修按钮，也不能无代价消除旧版的基础设施折旧。

## 7. 国家延续、制度与失败

用户要求：只要没有严重施政失败、极端失误或可避免的巨大军事失败，就持续控制。建议标准模式中普通政府下台或议会失势产生改革压力/执政篇章变化，不直接终局。公共设施、人口、知识、项目合同、欠付与债务按继承规则保留；新政府没有自动清债、清除负面民意或刷新资源的福利。

- 每次政府/制度更替产生一次明确的过渡成本与可选择方向；不能成为无限刷授权或清冷却的工具。
- 议会选举只在适用制度下出现；早期可由统治联盟与财政履约约束政权稳定。具体制度数量控制在少数几种治理规则组合，避免变成完整政治史模拟器。
- 债务危机可以引出有代价的重组、强制紧缩或外部限制，仍须真实过账并记入历史；不能以剧情弹窗抹掉债务。
- 最终终止条件暂建议：400年届满、用户主动结束、持续严重治理崩溃导致国家解体，或经战争/条约实际失去独立控制。具体阈值待标定；不把一次年度超限或一次选举失利当作整局失败。
- 可保留旧式“单届执政挑战”作为独立模式；旧 40 季剧本成为现代治理实验室/回归基准，不冒充新的主战役。

危机采用“预警 → 危机 → 最后补救窗口 → 结果”的公开状态机。赤字、物资短缺、合法性或补给各自独立显示，不合成一个神秘失败分数；每类危机列出触发事实与仍可采取的行动。严重性/持续时间的联合阈值和窗口长度待实测，不先杜撰固定年数。

“离谱选择”不能由作者主观判断哪种意识形态正确。终局只能来自可核对的承诺违约、长期基本供给崩溃、治理失效或战争损失等结果。大多数错误应先带来可恢复的衰退、改革压力或有代价的退让，玩家在损失中仍有决策。

### 7.1 外交、贸易与抽象战争（用户已确认范围）

发展始终占主要操作量。最小外部系统建议三类有独立利益的伙伴：贸易型、资源型、区域竞争型；具体数量待技术评审。它们有资源供需、关系、条约、行动意图与军事/融资约束，不需要模拟全球几十国完整经济。

- 贸易：选择伙伴与产品/配方对应物资，设立有运力和成本的进口/出口安排；国内短缺、外部断供、港口容量和依赖度产生取舍。扩大通道不能凭空创造外国库存或购买力。
- 外交：关系改善、贸易协议、互不侵犯/保障、争端谈判与让步。条约效果必须落到通行权、成本、额度或可信的援助义务，不只是一个关系加分数字。
- 危机：提出诉求→谈判与第三方立场→动员警告→退让或升级。战前公开已知目标、双方可见能力范围、预计资源负担及至少一条可行的避战/降级路径；不是所有避战选择都无代价。
- 战争：以地区方向/战区和季度战役结算，玩家选择有限目标、防御/推进、动员、补给投入与求和，不操控营级单位。战役分别受兵员、训练、装备、补给、地形/防御条件影响，不只靠“军力大者赢”的一次掷骰。
- 经济连接：动员从劳动年龄群组调人并支付军费；军需走真实采购与库存，影响企业用工和居民物资；伤亡、复员、设施损坏与修复都有明确状态和去向。不能既让同一人全职生产又全职服役。
- 结果：一般失败可导致赔款、贸易限制或有限权益损失，仍可发展；只有灾难性失败/丧失独立控制等公开条件才可能终局。赔款与损坏真实过账，和平不能清空旧债。
- 技术迭代影响训练、装备与物流方法；军事支持可复用教育、工业、交通设施，但独立营地/军需设施如有必要另列内容预算，不能偷偷塞进36个经济建筑目标。

外部主体从当前单一 `agent.row` 拆分时必须守恒分配初始现金/库存与贸易记录；不能给每个伙伴复制一份原外部世界资金。M3增加一条完整可避战的危机链及其有限战争分支，再逐步扩量；M2用贸易伙伴与一次外交选择验证方向。

范围边界：不做战术战斗、精细兵棋移动、完整全球AI和人物王朝谱系。军事胜负服务于国家发展的风险与代价，不成为替代经济玩法的征服循环。

## 8. 提高可玩性的内容纪律

1. 每项新内容必须带来行动差异：解锁新生产方式、打开新地点、替换依赖、改变风险或社会分配。无法指出新行动的节点暂不制作。
2. 为关键问题提供至少两个能成立的方案。例如粮食不足可投水利，也可改善运输与进口；工业缺工可培训，也可采用节省劳动的改造，但各自依赖不同资源。
3. 软性目标采用地区问题与时代工程：例如建立跨区粮食网络、让两个地区具备基础医疗、完成一条动力替代链。完成反馈记录实际改变，不用虚构货币奖励绕过经济。
4. 部分条件事件提供 2—3 个可执行方案。选项展开成本、对象、延迟与不确定性；只经命令/项目结算，事件系统不能直接任意写 GDP、库存或现金。旧“事件只改主观量”合同需专门修订后才能加入物质选项。
5. 通知按问题聚合，首屏最多突出少量可行动事项；完整台账折叠保留。玩家主要比较方案，不必每回合逐项核对几十个指标。
6. 设置关键过渡而不是四百年线性上涨：资源紧张、旧产业退出、城市化、财政制度升级、技能错配等均由可观察机制产生。随机事件不作为强行拉平领先玩家的橡皮筋。
7. 至少比较三条路线：农业公共服务、商贸引入、工业自主。不同路线应有各自的成本与优势；不要求每条都在所有条件下同样强。

## 9. 界面、文本与美术：Codex 主责

### 9.1 界面改造

首屏能看到：现在是哪一年、当前发展目标、关键限制、正在研究什么、正在建设什么，以及下一项需要玩家作决定的事项。深层规则卡、台账与“实/算/预”体系继续存在。

用户已选择建筑卡片和列表，参考《维多利亚3》类型。按地区管理产业规模和生产方式；地图展示地区条件、贸易/战区联系与历史变化，不加入自由摆放、道路寻路或有限地块拼图。土地与资源上限仍可作为地区数值约束；施工槽位只表示同期开工能力。

### 9.3 文本与玩法审视

Codex 建立跨时代术语表，逐页审核“共和国、总统/执政、GDP、电力、失业保障、现代税制”等词的适用阶段；早期主视图采用玩家可理解的产出、收支、人口和生活描述，专业核算口径可留在详情。

所有建筑/科技/事件卡使用统一结构：解决什么 → 需要什么 → 何时见效 → 谁受影响 → 失败条件 → 能否退出。不把旧现代政策换名称就当成早期制度。中文继续外置，数字用槽位。

每个阶段结束，Codex 根据实际运行截图和数据审查：能否发现下一步行动、是否存在唯一必选路线、点击是否重复、升级是否可见、描述是否承诺了不存在的效果；问题写入交接队列并附可复现场景。

## 13. 验收设计（拟新增，不是本轮已执行）

技术验收：

- 同种子同命令，逐季与年度/多年推进逐季哈希一致；暂停/恢复、存读档与中断重启不重复付款/科研/投运。
- 科技依赖无环、不可重复领取解锁、未满足试点条件不产生推广效果；切研究和重载不复制进度。
- 改造期间旧/新产能不双计；设备、现金、材料、人口按对应守恒核对；施工完成下一季投运。
- 政府更替和制度变更保留资产债务，不重置研究奖励、冷却或违约；旧现代模式的结束条件保持独立。
- 危机预警在终局前可见且有可执行补救；可避免的战争能用规则内行动避免，有限战败不自动终局。动员/伤亡/复员人口守恒、采购与赔款双边入账，重载不能重抽战役结果或重复领取和平收益。
- 1,600 季的数值边界、容量回收、账块归档和重放完整性；至少三条有效策略加无操作/高压策略，每条用多个种子。合法提前终局计为策略结果，同时另设能跑满的长局基准，不能再次出现“有合法终局却要求全部活满”的性能协议错误。
- 每次运行记录实际季度数、峰值内存、存档/日志大小、每季中位数与 P95、加载/恢复时间，先测再定新门槛。

玩法验收：

- 切片结束后测试者能说出当前限制、一个被放弃方案及其代价、一次升级的配套条件。
- 至少两条路线能形成不同的设施结构和社会结果；没有一项科技在所有测试局都成为无条件必选。
- 记录空操作时间、重复确认次数、每十年有意义的决策数、首次升级用时、误解原因；“节点数量达标”不能替代好玩。
- 用真实窗口检查1600×900、1366×768及150%缩放；建筑缩到64 px、科技图标缩到24 px仍可辨，正文无需依赖图片内文字。
