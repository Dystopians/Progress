## 2 行动脚本（用户 2026-09-23 提出）

把一局的动作写成 JSON（`tools/playscripts/*.json`），游戏按季度经真实命令路径提交并推进，逐位可复现。

- 核心：`application/playscript.gd`（`JWPlayscript`）。文字 ID 在开局时解析，写错立即报出。
- 无界面：`tools/play.gd`，打印年表与被拒动作，可另存存档。
- 带界面：`--jw-play=<脚本> [--jw-play-until=1650秋]`，开局后快进并停在截止季；截图工具同样适用。
- 路线甲、乙改写成脚本后，与 `tools/route_compare.gd` 的结果逐位相同（种子 1、200 季：甲 GDP 4.50、失业 62.2%；乙 6.86、47.3%）。
- 以后调试、截图、对照局都用脚本开局，不再依赖旧存档；机制改了只需重跑脚本。
- 格式说明：`tools/playscripts/README.md`；测试：`tests/scenario/playscript_test.gd`（6 项）。
