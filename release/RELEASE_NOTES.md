# 经纬 · 版本说明

> 草稿：版本 0.1.0-dev（首版机制验证版）。界面验收完成后定稿；只写已经落地并有测试的内容。

## 这是什么

一个按季度推进的国家发展模拟：你执政一个虚构国家「澄湾共和国」10 年（40 季），只能动用制度授权的工具——
政策、项目、国债与支出排序——不能直接设定 GDP、民意或库存。结果由同一套公开规则一次结算，全部记入复式台账，可以逐笔追溯、逐位重放。

## 本版包含

- **核心模拟**：4 地区 × 4 部门的投入产出、库存与价格；36 个人口群组的就业、收入、消费、迁移、教育与住房；
  逐批次计息的国债、预算审查、选举与集团否决；三类外部冲击（出口需求、进口价格、外部融资）。
- **12 项政策**：所得税、利润税、失业保障、海岬电网、培训、公共住房、灌溉与物流、港口、设备投资补助、基础医疗、税务征管、采购透明。
  每项都有资格条件、时滞、真实成本（开关成本、项目期支出与投运后运行费）与退出规则。
- **项目合同**：立项、取消（付合同赔偿）与延期（付延期赔偿，次数与累计季数有上限）；付款不制造进度。
- **12 类事件**，按条件与概率触发，只改变主观量（生活、预期、信任、支持）、行政执行能力与集团立场，不直接写现金、库存、产能或人口（INV-130）；
  触发次数与冷却随存档保存，本季触发的事件逐条写进季度报告。
- **五个页面**（总览、地区、政策工作台、社会、季度报告）与预算审查、推进确认、结算回放、台账与规则卡。
- **图形**：地区多边形图（邻接与物流成本取自剧本）、走势图、分布条（P10 / P50 / 均值 / P90）、未来 12 季承诺时间轴；每张图写明时间范围、单位、价格基期与分母。
- **术语首见**：各页「本页术语」条与术语定义卡（定义、本局实例、规则手册锚点）；规则手册列出全部事件的公开触发条件。
- **可复现**：同一种子 + 同一命令流逐位相同；每季自动存档与检查点，权威重放可从第 0 季逐季比对。

## 质量状态

- 自动测试：单元、场景、对抗（套利、融资、合同、物理约束）、重放与压力测试全部通过（见 docs/40）；界面冒烟测试走完 40 季。
- 无命令、无冲击基线：40 季零欠付、预算审查零失败、两次选举留任。
- 12 项政策逐项做过单一干预检验；迁移、投资、价格与工资响应速度做过 ×0.5 / ×2 敏感性检验。
