# 经纬 · 操作指南

> 草稿：按 docs/20（界面规格）与当前界面写成；发布前按最终界面逐项核对。

## 开局

启动游戏后出现「开始执政」对话框：

- **随机种子**：只决定外生冲击的抽样。同一种子加同一串命令，结果逐位相同（可复现）。
- **任期目标**（可不选）：产业升级 / 民生优先 / 财政修复。只影响档案中的对照项，不改变任何规则，也不产生评分。
- **界面缩放**：100%—200%，也可用命令行 `--ui-scale=1.25` 指定。

你将执政 40 个季度（10 年）。经济下滑本身不会让执政结束；选举落败、连续失去留任资格或财政重组失败会提前结束。

## 每一季怎么走

1. **看**：五个页面（按 `1`—`5` 切换）呈现上一季已结算的结果。
2. **起草**：在「政策工作台」通过、调整或撤销政策，立项或取消项目，发行国债。命令先进**草案**，不会立刻生效。
3. **预算审查**（`Ctrl+Enter`）：底部固定区汇总本季草案的支出、四季现金最窄余量与新增长期承诺；有阻断项时必须先处理。
4. **推进**（`Ctrl+Shift+Enter`，不响应单独的 Enter）：确认框列出这一步不可撤回的全部后果，确认后一次结算八个步骤。
5. **回放与报告**：结算回放按「审核与融资 → 生产与交易 → 财税与社会」三段展示；随后查看季度报告。

每季末自动存档。

## 五个页面

| 页 | 看什么 |
|---|---|
| 1 国家总览 | 实际产出、地区图（图层可切换；窄屏为四格横条）、财政与执政结束判据、六张走势图、未来 12 季已签承诺时间轴 |
| 2 地区 | 各地区的人口、就业、电网、住房、公共服务与项目槽位 |
| 3 政策工作台 | 12 项政策的状态、时滞、成本、为何现在不能执行（原因卡），以及项目与国债 |
| 4 社会 | 36 个群组的生活、服务可及、支持度；分布而不是单一平均数 |
| 5 季度报告 | 本季发生了什么、规则推断了什么、情景预测是什么，三者分开写；本季触发的事件列在「已经发生」里 |

## 三类信息（顶栏「实 · 算 · 预 图例」）

- **实**（已经发生）：已结算、能定位到台账某一行的数。
- **算**（规则推断）：由已结算状态按公开规则确定性算出的数，不依赖未来。
- **预**（情景预测）：依赖未来经济或未提交的草案，一律带区间与情景名。

可以隐藏未来冲击，但不隐藏当前规则：任何带引用的数字都能打开**台账**（`Enter`）或**规则卡**（`Alt+R`）看到它从哪里来。

## 常用快捷键

| 键 | 作用 |
|---|---|
| `1`—`5` | 切换页面 |
| `Enter` / `Alt+R` | 打开当前数字的台账 / 规则卡 |
| `Esc` | 逐层收起（模态 → 抽屉 → 展开的区块） |
| `Ctrl+Enter` | 预算审查 |
| `Ctrl+Shift+Enter` | 推进季度确认框 |
| `Ctrl+[` / `Ctrl+]` | 台账抽屉的历史前后 |

## 几条值得先知道的规则

- **税制与法定支出**（P01、P02、P06、P10）只能在预算审议季（每年第 4 季）提出，下一季起生效。
- **政策开关有真实成本**，且有冷却期；已在执行的政策改参数有时滞。
- **项目**占用地区的施工槽位，付款不等于进度；取消要付合同赔偿，已付的钱不退。
- **项目延期**（季度报告的「暂停 / 改期」，或政策工作台项目行的「延期…」）：延期期间不付款、不推进，槽位照占；
  当季按剩余合同额每季 1.5% 付延期赔偿。每个项目至多延期 2 次、累计 8 季。
- **国债**按批次记账：旧债不因新利率重新定价；偿债率越高，新发票息越高。
- **预算审查**每年一次：四季赤字超过收入的 15% 或欠付超限即审查失败；连续两次失败失去留任资格，再持续两季即执政结束。
- **海岬的电网**开局就偏紧，约两年后开始限制当地制造业（P04 可以解决，但要花钱、要时间）。
- **事件**按条件与概率发生，只影响民意、预期、行政能力与集团立场，不直接动钱和产能；情景预测不含事件。
- **立项**和政策一样要过资格链：法定权限、执政席位、集团否决；公共住房（P06）还要等预算审议季。

顶栏「存档 / 读档」。存档核对内容包版本：用旧版本内容生成的存档只能只读检视，不能继续推进。
