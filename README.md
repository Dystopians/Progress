# 经纬 / Project Jingwei

> **方向更新（2026-09-22）**：用户已确定改为 **1600—2000 年、跨越400年的国家发展游戏**，加入科技树与跨时代建筑/升级，尽量复用当前工程。发展为主，含外交贸易与抽象战争；建筑采用卡片/列表，参考《维多利亚3》类型；正常施政持续控制，严重失败才可能终局。现有代码仍是下述现代40季机制验证版。新方向见[改造提案](docs/_drafts/50_four_centuries_redesign.md)，分工、咨询与进度见[Codex↔Claude动态交接](docs/51_codex_claude_handoff.md)。具体新机制尚未实施。

> 一个会因发展而改变的国家。
> 玩家不是给国家加点——玩家改变生产与生活的条件，再面对由这些改变产生的新社会、新诉求与新约束。

以现代发展机制为基础的**单人回合制国家治理游戏**。首版是可完整游玩的机制验证版：
1 个架空国家（澄湾共和国）、4 个地区、36 个人口群组、4 个部门、12 项政策、12 个事件模板、3 类外生冲击、40 个季度。

权威需求文档：[`docs/ref/plan_v1.0.txt`](docs/ref/plan_v1.0.txt)（项目计划书 v1.0，19 页）。
该计划书记录旧版产品范围；当前执行契约以 `AGENTS.md` 所列裁定优先级为准。新的400年产品方向由用户确认，详细改造提案须经裁定与契约更新后实施，不能把未落地提案当成现有功能。

## 快速开始

```bash
# 总闸门：分层检查 + 解析检查 + 全部测试
bash tools/gate.sh

# 解析闸门：所有 .gd 必须可编译、可实例化
bash tools/check.sh

# 测试（unit / replay / scenario / stress / ui）
bash tools/test.sh
bash tools/test.sh --suite=unit --verbose
bash tools/test.sh --filter=ledger
```

引擎与构建环境已锁定，见 [`docs/ENGINE.md`](docs/ENGINE.md)：**Godot 4.7.2-stable + 带类型 GDScript**。
重放确定性只在该固定构建下承诺。

## 不可削减的底座

即使压缩内容，以下六项必须保留（计划书 §03）：

| 底座 | 含义 |
|---|---|
| 账目一致 | 每笔交易双边入账，残差恒为 0 |
| 物资约束 | 产量由最紧的约束决定，不能凭空生产 |
| 建设时滞 | 支出先发生，能力后形成；当季完工的资产下一季才供能 |
| 政治反馈 | 发展会产生新的受益者与新的反对者 |
| 因果说明 | 报告要把问题定位到机制，而不是只显示红色数字 |
| 存档重放 | 同构建 + 同种子 + 同命令流 ⇒ 逐位相同的状态 |

## 已锁定的工程决策

- **整数定点算术**：SimCore 内禁止 float 参与任何影响状态的计算。
  货币单位 `μU`（1 U = 1 000 000 000 μU，裁定 R-SCALE-01），实物单位 `μQ_s`，比率一律 `ppm` 整数。
  除法向下取整，余数显式登记或按最大余数法分配——任何拆分后各项之和必须精确等于原额。
- **四层架构**：`sim/`（SimCore，不得依赖场景树与 UI）→ `systems/` + `application/`（命令校验、回合调度、存档、重放）→ `ui/`（只读渲染，不得直接改状态）→ `content/`（剧本与参数，不得隐藏不可追溯的副作用）。
- **生成式 AI 不进入权威结算**。报告使用规则模板。Python 只用于离线校验与校准，不维护第二套模拟核心。

## 目录

| 路径 | 内容 |
|---|---|
| `sim/` | 模拟核心：状态、账本、部门、人口、政策、项目、政治、外部 |
| `systems/` | 回合调度、命令、存档 |
| `application/` | 应用层：命令校验、回合驱动、重放 |
| `ui/` | 五个主页面：总览 / 地区 / 政策工作台 / 社会 / 季度报告 |
| `content/` | 剧本、政策、事件、冲击、参数登记 |
| `tests/` | `unit` / `replay` / `scenario` / `stress` / `ui` |
| `tools/` | 无界面闸门脚本与 Python 离线分析 |
| `docs/` | 变量字典、数据协议、结算合同、参数登记、待决问题、裁定、界面规格、进度与发布清单 |
| `release/` | 操作指南、版本说明、已知限制、反馈表、样例存档 |
